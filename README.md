# Dino_Nuggets 🦖

**A playful, dinosaur-themed CAPTCHA-inspired game.**

- **Live Demo:** https://humanexe-25-second-human-check--shivamkhera2008.replit.app
- **Source Code:** Download `Dino_Nuggets_source.zip` from this repository.

Dino_Nuggets reimagines CAPTCHA-style verification as a fun, prehistoric mini-game experience. It is a prototype for entertainment and does not provide real bot detection or security.
